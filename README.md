Privacy Policy for Force Light Mode for Gemini

Effective Date: 2026-01-01

Force Light Mode for Gemini is a Chrome extension that applies local styling to Gemini pages in order to force Gemini to display in light mode.

Data Collection

This extension does not collect, store, transmit, sell, or share any personal information or user data.

The extension does not collect Gemini account information, prompts, conversations, browsing history, cookies, authentication information, or any other personal data.

Use of Host Permission

The extension requests access to https://gemini.google.com/* only so it can apply local CSS styles on Gemini pages. This permission is used solely for the extension’s single purpose: forcing Gemini to display in light mode.

Data Sharing

This extension does not transfer or sell user data to third parties.

This extension does not use user data for advertising, analytics, creditworthiness, lending, or any unrelated purpose.

Remote Code

This extension does not use remote code. All executable code and styling are packaged locally within the extension.

Limited Use Disclosure

The use of information received from Chrome extension permissions will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
